# planning/

> L2 | 父级：[项目约定](../../../AGENTS.md)

采集前的目标规划、命名预设和确认。自然语言归一与用户对话由 Agent 完成，执行、恢复和预算继续使用 `tasks/`。公开契约见 [docs/planning.md](../../../docs/planning.md)。

- `__init__.py`：包入口。
- `models.py`：带版本规划、可选方案、预设与偏好白名单；单次输入不进入预设。
- `routes.py`：复用目标依赖、能力契约和来源排序，按需查相关报价，保留条件费用与未知覆盖范围。
- `store.py`：私有规划原子写入、内核锁与命名预设版本冲突检查，不覆盖并发修改。
- `service.py`：结构匹配、方案生成、显式选择、运行前复核、预设保存和执行前任务绑定。
- `cli.py`：`plan create/show/select/run` 与 `presets list/show/delete`。

匹配只返回候选；无确认不执行。预设不能启用当前停用的来源、降低当前费用保护、冻结旧报价或重置旧任务预算。规划不做网站采集、余额查询或后台轮询。方案不能以元数据接口的可调用性冒充正文/媒体转换能力。
